## Reporting a Vulnerability

If you discover a potential vulnerability, cryptographic weakness, or security flaw across any repository in this organization:
1. Do not open a public GitHub issue.
2. Email full vulnerability telemetry, reproducible proof-of-concept, and environment details to **`jk9576@hanyang.ac.kr`**.
3. PGP / GPG encryption is available upon request for sensitive disclosures.
4. An acknowledgment will be issued within 24 hours with an initial severity triage.
